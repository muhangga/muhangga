## What I work on

Right now I build Go services on Google Cloud and Firebase for Autsorz, a multi-tenant field-operations app
(Cloud Functions, Cloud Run, Pub/Sub, BigQuery, Firestore). Before that I built an SMS gateway used by 100+ companies,
ERP modules for finance, payroll and attendance, and worked on a Spring Boot + Angular system for a bank.

Some things I've shipped:

- Ported a config service from Node.js to Go, taking the app launch check from 32 s to 2.1 s.
- Wrote a Go migration tool with dry-run mode and hash checks for moving production data between GCP projects.
- Built an event pipeline on Pub/Sub that writes to Firestore and keeps an audit trail in BigQuery.
- Designed and built an SMS gateway on RabbitMQ, Redis and event sourcing.

Most of that lives in private company repositories, so the public repos below are older side and learning projects.
